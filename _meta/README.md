# _meta

Config for the vault. Read by `_tools/kos_capture_hub.py`, not by Obsidian.

- `domains.json` — the ONLY place to add/rename domain buckets. Edit here, restart the capture hub, done.
- `concept-registry.md` — auto-appended each time a concept is promoted from a project `Concepts/` folder to `04 Knowledge/`.  Do not edit by hand.
- `.active_project` — sticky project selection remembered between hub launches.

Never put actual notes here.
