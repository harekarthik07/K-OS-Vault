Workflows
MRF (Multi Reference Frames) Simulation
•Geometry Preparation: Import or create the rotating and stationary fluid domains.
•Physics Setup: Define fluid properties, rotation speed, boundary conditions, and MRF region.
•Resolution Setup: Adjust mesh resolution and define the required level of flow detail.
•MRF Setup: Assign the rotating region and specify the rotational axis and speed.
•Simulation: Run the steady-state CFD analysis and monitor convergence.
•Results Visualization: Evaluate pressure, velocity, streamlines, torque, and other flow parameters.

Best Practices
MRF Simulation
Set Correct Rotation: Verify axis, direction, and RPM.
Refine Critical Regions: Use finer resolution near blades, tips, and wakes.
Check Interfaces: Ensure smooth transition between rotating and stationary regions.
Monitor Convergence: Track residuals and key quantities such as torque and pressure rise.
Validate Results: Compare performance with experimental or published data where available.
Porous Media Simulation
Define Porous Region: Accurately represent the thickness and location of the porous medium.
Use Correct Properties: Define fluid properties and porous resistance coefficients accurately.
Choose Directionality: Select isotropic, bidirectional, or orthotropic resistance based on the physical
medium.
Refine Near Porous Region: Ensure adequate resolution around the porous interface.
Check Pressure Drop: Monitor pressure loss across the porous medium.
