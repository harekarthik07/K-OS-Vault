# Project Template

Copy this whole folder into `03 Projects/` and rename it to your project name.
Every project uses this exact shape so the capture hub, dataview queries, and
the Friday harvest ritual all work without config.

Files with a leading `_` (like `_concept-template.md`) are Templater sources —
`Ctrl+P` → "Templater: Create new note from template". Delete them from the copy
you make; they're not project content.
