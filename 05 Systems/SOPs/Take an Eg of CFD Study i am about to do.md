Every project should generate three kinds of notes.

For your **T30 Aerodynamic Study**, imagine this:

```
03 Projects
│
|
|── T30 Aerodynamic Study       
├── Daily Log.md      
├── Experiments.md      
├── Questions.md      
└── Results.md
```

At the same time, if we discover something generally useful, it goes into:

```
04 Knowledge
- Fault Tolerant Meshing.md
- Inflation Layers.md
- Watertight Geometry.md
- Mesh Quality Metrics.md
```

And if we refine a reusable way of working:

```
05 SystemsCFD Study Workflow.md
```

One day's work creates assets in three places:

- **Project** (what you're doing),
- **Knowledge** (what you'll reuse),
- **System** (how you'll repeat it).
