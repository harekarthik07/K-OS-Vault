# K-OS Commands

The working method runs on three commands. When Sarath types one to Claude, Claude follows the matching SOP. Templates for each live in `_templates/`.

| Command | When | SOP | Template(s) |
|---|---|---|---|
| **`/start [project]`** | new project | [[/start — kick off a project]] | Universal / CAE preset + note-set |
| **`/eod`** | end of a work day | [[/eod — compile the day]] | Daily_EOD_Template |
| **`/weekly`** | Friday or Saturday | [[/weekly — harvest to the Ideaverse]] | Weekly_Review + Knowledge_Page |

Governing doc: [[K-OS Operating Brief (v2)]]. Two loops — **project engine** (daily) feeds the **Ideaverse** (weekly); the Ideaverse feeds back into `/start` and the phase gates.

> Supersedes the v1 [[K-OS Workflow (Master)]] set (kept for reference).
