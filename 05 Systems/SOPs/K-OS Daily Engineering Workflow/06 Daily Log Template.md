Move it to Archive only when the project is completed.

Example:

```
Projects
│
├── T30 Aerodynamic Study
│   
    ├── Daily Logs
    ├── 2026-07-08.md
    ├── 2026-07-09.md
│   ├── 2026-07-10.md    
    └── ...
    │      
    ├── Experiments.md  
    ├── Results.md   
    └── Lessons Learned.md
```

When the project finishes:

```
Archive
│
└── T30 Aerodynamic Study     
    ├── Daily Logs     
    ├── Results     
    └── Lessons Learned
```

The daily logs become part of the project's history.
