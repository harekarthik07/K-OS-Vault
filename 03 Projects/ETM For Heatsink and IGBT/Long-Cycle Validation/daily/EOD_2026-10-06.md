# EOD — 2026-10-06

## What we set out to do
Fix yesterday's contaminated C extraction (C fit -> 1321 J/K, non-physical) by
separating airflow from capacitance, and find the effective h for different cooling
conditions.

## What we actually did
- `/start` on a (h,C) joint fit -> **redesigned to h-only.** C is CAD-derived; fitting it
  invites the optimizer to move it off its true value (that is how 1321 happened).
- Sections 1-4 worked: one error x one parameter = well-posed; RMSE(h) is a single bowl
  (h -> R_conv monotonic -> error crosses zero once).
- Delivered `fit_h_cycle.m` (standalone, manual) and a **"Fit h to cycle"** app button
  (sweeps h 5-80, C locked, plots RMSE + bias vs h, verdict to readout).
- Lag moved into the T_ntc **plot title** (bottom readout line was clipped off-window).
- App sweep floor lowered 15 -> 5 after the fan-off run clamped at the edge.
- Concept note written: [[HS_Transient_Physics_h_and_C]].

## Results & numbers

C locked at **2402 J/K** for every fit.

| Run | Condition | best h (W/m2K) | RMSE (K) | bias (K) | lag |
|---|---|---|---|---|---|
| dyno calibration (11 runs) | MC fan, bench | **29.59** | 2.05 | +1.89 | - |
| WLTP #0045 | dyno, low load | 29.59 fixed | 0.69 | - | - |
| BK-45 offc fullpush w-Fan | fan on, low speed | **22.39** | 1.22 | +0.28 | +0 s |
| fan-off run | fan off | **14.18** | 2.06 | +1.56 | +0 s |
| road run | real road | **18.78** | 3.20 | +0.33 | +0 s |

Same runs at the dyno h = 29.59, for reference: fullpush RMSE 3.87 / bias +3.53;
fan-off RMSE 10.26 / bias +9.03 — every real condition runs hotter than the dyno h predicts.

**Findings**
1. **C = 2402 J/K validated on every run (lag = +0 s).** Capacitance is right and
   condition-independent. Closed.
2. **h spans ~14 -> 30 across cooling states** — more than 2x. One fixed h cannot
   represent the system.
3. **Every field condition fitted below the dyno h.** Dyno appears to over-cool vs the
   field (tentative — see h_eff caveat).
4. **Fan-off h ~ 14 is the deration-critical floor.** The fan-off run reached ~95 degC
   measured. Thermal protection calibrated at h = 29.59 under-predicts junction temp
   by several K exactly when cooling is weakest.
5. Fan-off: RMSE minimum (14.18) and bias-zero (~11) don't coincide -> small residual
   h cannot remove. Both in 10-14 band; conclusion holds.

## Decisions made and why
- **h-only fit, C locked.** h and C are degenerate on a level error; locking C makes the
  fit unique and lets lag validate C independently.
- **Fit results are h_eff**, a single constant for a time-varying h(t). Road h_eff = 18.8
  is an average across moving + slow segments, not proof that road airflow is weak.
- **Corrected bias interpretation** logged: bias > 0 = model over-cooled = true h lower.
